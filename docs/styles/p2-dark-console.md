# 预设 P2 · 深色数据台

> 监控 / 运营 / 数据密集场景。信息密度高，适合长时间盯着看的场景。

## 色板

```text
主色  ██ #0ea5e9   brand-600    按钮、主强调、图表主色（亮青，深底上更醒目）
浅主  ██ #075985   brand-100    标签底色、提示条
页面  ██ #0b1220   surface-page 页面背景（近黑蓝）
卡片  ██ #111a2b   surface-card 卡片、面板、表格
文字  ██ #e2e8f0   text-primary 标题与正文
次文  ██ #94a3b8   text-secondary 说明文字
弱文  ██ #64748b   text-muted 占位提示、时间戳
边框  ██ #1f2b3d   border-base  卡片边框、分隔线
危险  ██ #f87171   danger-600   错误态（浅红，深底可读）
成功  ██ #4ade80   success-600  成功态（浅绿）
```

> ⚠️ 语义色在深底上**比 P1 更亮**——直接沿用 P1 的 `#dc2626` 会看不清。

## 字阶

同 P1（title 24 / subtitle 18 / body 16 / caption 12）。

## 版式

```text
圆角  同 P1（小 4px / 中 8px / 大 12px）
间距  【比 P1 更紧】页面 16px  卡片内边距 16px  区块间 24px
阴影  【深底上几乎不用】深底本身有层次感，浮层改用 border + 更亮的边框色
```

## 适合什么客户

- ✅ 监控大屏、运营中心、值班大屏
- ✅ 数据密集的报表 / 看板
- ✅ 客户本身偏好深色界面（科技类、金融类尤其常见）

## 不适合什么客户

- ❌ 打印、投屏给非技术客户时——深底在投影仪上容易发灰、发虚
- ❌ 表格内容很长的场景——深底长时间阅读更累
