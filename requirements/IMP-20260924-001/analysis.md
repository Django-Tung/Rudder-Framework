# 导入分析与候选拆分

## 文档概览

- 来源：投研智能体业务需求 V1.3，文档编号 ZSRZ-YGZB-2026-001。
- 业务范围：围绕投前、投后两大场景，覆盖信息采集、多模态解析、信息归集、智能研判、项目管理、报告生成、智能对话、外部系统对接、权限与系统设置。
- 核心业务主线：采集—解析—提取—归集—分析—输出—归档。
- 已确认项目 UI 主风格：数据密集型投研工作台。
- 本次分析只进行功能边界和依赖的粗拆分，不定义验收标准、页面结构、UI 状态、数据模型、服务契约或实现任务。

## 已确认的范围与共享规则

- 本期采用数据密集型投研工作台风格，强调项目、指标、舆情、研判和报告信息的高密度浏览、筛选与追溯。
- 信息源、经营指标、尽调规则、报告模板、潜在项目关注配置先使用模拟数据或模拟配置；具体真实数据和规则在 Plan 阶段补充。
- 红黄绿研判规则按行业配置，具体阈值和维护责任在 Plan 阶段确认。
- 产业链分析与主动寻源本期不纳入范围。
- 千里马平台对接纳入功能边界，但本期直接使用模拟对接，不代表真实数据抓取已获合规批准。
- 无研判结论时，置信度显示为“暂无研判”，不参与项目整体最高置信度计算。
- “中数睿智”作为已确认的在管项目名称保留。
- 复合模式、正式预览、电子印章本期不纳入报告中心范围；基础报告生成、编辑和导出能力保留为候选功能。
- 小程序指标分享复用现有账号体系，分享内容仅限核心指标并遵循文档中的有效期和脱敏约束。

## 候选功能点

- REQ-001 信息采集与采集动态：维护模拟信息源与采集规则，采集政策、项目、公告和竞品动态，提供去重归并、动态时间线和详情追溯。
- REQ-002 多模态解析与信息归集：解析文本、图片及文档等采集内容，提取项目、舆情、政策要素，分别归集至投研知识库和舆情信息库，并支持人工复核。
- REQ-003 智能研判与风险规则：基于信息来源、证据和推理链形成研判结论，提供置信度、情感判断、红黄绿风险分级、法务风险识别和规则配置。
- REQ-004 投后项目管理：管理在管项目、舆情画像、政策影响、指标跟踪、竞品动态、预警处置、机会共享和操作记录。
- REQ-005 投前项目管理与尽调：管理潜在项目、跟进状态、竞品跟踪和尽调检查清单；产业链主动寻源不在本期范围内。
- REQ-006 报告中心：基于模拟模板生成投后月报、半年度/年度报告、专项研判报告和项目清单报告，支持章节采纳、修改、基础导出和归档查询。
- REQ-007 智能对话与反馈：支持投前研判、投后分析、知识检索和报告生成对话，展示来源与核实状态，并收集正负反馈和研判采纳/误判样本。
- REQ-008 外部系统对接与指标分享：覆盖企查查、法务风险提示、千里马模拟对接，以及复用现有账号体系的小程序核心指标分享。
- REQ-009 权限与系统设置：提供按部门、角色、项目和模块的数据访问隔离，以及信息源、采集规则、研判规则、尽调要点和反馈样本配置。

## 依赖关系

- 信息采集是解析、研判、投后和投前功能的基础。
- 多模态解析与信息归集依赖信息采集；智能研判依赖解析和归集结果。
- 投后项目管理与投前项目管理依赖采集和智能研判能力。
- 报告中心依赖研判结果及投前、投后业务数据；智能对话依赖知识库、舆情库、研判和项目数据。
- 外部系统对接与指标分享依赖项目管理及权限能力。
- 权限与系统设置作为横向支撑能力，可独立规划。

- 尽调规则清单、检查标准和报告模板的正式版本。
- 千里马真实对接前的合规审查结论及允许的接入方式。
- 权限复用时现有账号体系的接口和领导账号授权边界。
