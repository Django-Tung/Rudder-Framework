# 预设 P3 · 温暖内容型

> 消费级 / 留白多 / 亲和力。圆角更圆润、留白更多，不像「后台系统」。

## 色板

```text
主色  ██ #ea580c   brand-600    按钮、主强调（暖橙，活泼但不刺眼）
浅主  ██ #ffedd5   brand-100    标签底色、提示条
页面  ██ #fffdfb   surface-page 页面背景（暖白，非纯白）
卡片  ██ #ffffff   surface-card 卡片、面板
文字  ██ #1c1917   text-primary 标题与正文
次文  ██ #6b5f57   text-secondary 说明文字（暖调灰）
弱文  ██ #a89b91   text-muted 占位提示、时间戳
边框  ██ #f0e9e3   border-base  卡片边框、分隔线（暖调）
危险  ██ #dc2626   danger-600   错误态
成功  ██ #16a34a   success-600  成功态
```

## 字阶

同 P1（title 24 / subtitle 18 / body 16 / caption 12）。

## 版式

```text
圆角  【更圆润】小 6px   中 12px   大 16px
间距  【留白更多】页面 32px  卡片内边距 32px  区块间 48px
阴影  【更柔】sm 极轻   md 更扩散（0 4px 16px）
```

## 适合什么客户

- ✅ C 端 / 消费级产品（电商、内容、社区、健康、医美）
- ✅ 品牌调性偏温暖、亲和、注重观感的客户
- ✅ 营销页、落地页、活动页

## 不适合什么客户

- ❌ 高密度数据管理后台——留白多会浪费屏幕空间
- ❌ 需要专业严肃观感的企业客户
