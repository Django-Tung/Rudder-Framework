# 全局主 PRD

> 本文件是项目级需求主记录。它记录跨 REQ 共享的业务规则、术语、已确认的 UI 主风格和待批准的需求拆分。
> 不属于任何阶段，不设置 `status` / `phase`。REQ 的状态与索引由各 REQ 的 `README.md` 和自动索引维护。

## 1. UI 主风格

- 预设：`P1` · 清爽后台
- 来源：用户未指定，采用默认预设
- 令牌集：`src/index.css` 的 `@theme`（随预设同步，取值见 `.rudder/design/visual.md` §4）
- 例外：无
- 确认日期：2026-10-02

**取值只允许**：`P1`（清爽后台）/ `P2`（深色数据台）/ `P3`（温暖内容型）/ `BRAND`（客户品牌色派生）。
**不接受自由文本描述**——用户无法描述视觉，预设包图示见 [`docs/styles/`](../docs/styles/)。

> 首次执行 `/rudder-import` 或 `/rudder-plan` 时，向用户展示三套预设图示并询问：
> 「① 选 P1 / P2 / P3 哪一个？② 或者直接说『你决定』」。
> 选 ② 即采用默认预设 `P1` 并记录「用户未指定」——**流程不得因此卡住**。
> 后续入口必须展示当前预设并询问是否沿用或调整。
