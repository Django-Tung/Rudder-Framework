<a id="_Toc239152246"></a>__一、文档说明__

## <a id="_Toc239152389"></a><a id="_Toc239152247"></a>（一）编制目的

本确认书基于2026年8月11日需求沟通会议、2026年8月28日客户需求反馈及2026年8月31日原型演示与需求对接会议纪要编制，将业务需求梳理为结构化需求条目，供双方逐条确认。经双方确认后的需求条目将作为投研智能体系统建设的需求基线，后续系统设计、开发与验收均以此为准。

## <a id="_Toc239152250"></a><a id="_Toc239152392"></a>（四）适用范围

本确认书覆盖投研智能体系统信息采集、智能研判、投后管理、投前管理、报告生成、对话交互、外部系统对接、权限管理、系统设置及数据安全等业务需求范围。

# <a id="_Toc239152393"></a><a id="_Toc239152251"></a>二、业务现状与需求背景

## <a id="_Toc239152394"></a><a id="_Toc239152252"></a>（一）业务模式

投资业务以直投为主，不涉及母基金、子基金业务，业务环节涵盖投前项目筛选与研判、投后项目管理与退出。智能体建设需求主要围绕投前、投后两大业务场景及配套系统能力展开。

## <a id="_Toc239152395"></a><a id="_Toc239152253"></a>（二）现状痛点

董事、股东层面对在管项目情况多为被动接收反馈，缺乏主动捕获舆情、提前介入的手段；

政策类、舆情类信息分散于公众号、新闻、专家渠道，缺乏统一采集、归集与研判机制；

投后报告依赖人工编制，模板复用与编制效率有待提升；

投前业务逻辑多沉淀于个人经验，缺乏系统化沉淀与共享渠道。

## <a id="_Toc239152254"></a><a id="_Toc239152396"></a>（三）建设方向

通过建设投研智能体，实现信息主动获取、风险提前预判、报告自动生成、投前投后协同。经2026年8月31日原型演示确认，系统采用Web端工具型架构，以信息采集与智能研判为主线，规划六大功能模块：信息采集、智能研判、在管项目（含潜在项目）、智能对话、报告中心、系统设置。

# <a id="_Toc239152255"></a><a id="_Toc239152397"></a>三、需求总览

## <a id="_Toc239152398"></a><a id="_Toc239152256"></a>（一）业务主线

投研智能体围绕"采集—解析—提取—归集—分析—输出—归档"七个环节形成业务闭环：智能体自动采集公众号等信息源内容，对多模态信息进行解析，提取结构化要素，按政策类、舆情类分别归集至知识库与信息库，结合风险规则与业务逻辑进行分析研判，输出报告或对话式分析成果，最终统一归档管理。

## <a id="_Toc239152403"></a><a id="_Toc239152261"></a>（三）采集方式与频次

智能体按既定规则实行全量采集，采集时效按信息类型配置：舆情信息以近30天为主（突发舆情即时采集），政策库信息时间范围放宽至近12个月（覆盖中长期政策影响），上市公司公告近12个月（手动搜索\+入库），招投标信息近6个月（合规审查通过后启用）。采集的信息经去重归并后入库呈现。

## <a id="_Toc239152262"></a><a id="_Toc239152404"></a>（四）竞品信息采集

系统可基于工商注册数据（经营范围关键词匹配）及共同投资、共同投标信息自动识别竞品企业，并采集其相关动态；亦支持人工指定竞品名单进行重点跟踪。竞品名单由提供或在使用中逐步积累。

## <a id="_Toc239152263"></a><a id="_Toc239152405"></a>（五）采集动态与详情展示

系统提供采集动态时间线，按时间倒序展示每条采集信息的时间、信息源、类型标签（新闻资讯/政策/系统解析/系统记录）、情感标签（正面/中性/负面）、关联项目。支持按时间范围（近7天/30天/90天）和信息类型筛选。

点击采集动态条目可展开详情抽屉，展示信息来源、采集时间、完整内容；若涉及本体推理（未直接命中关键词但通过因果关系关联），展示完整推理链：触发方式—因果关联节点—关联项目—推理置信度。

# <a id="_Toc239152406"></a><a id="_Toc239152264"></a>五、多模态解析与数据提取需求

## <a id="_Toc239152265"></a><a id="_Toc239152407"></a>（一）多模态解析【建议】

对采集内容中的图片（截图、海报、图表）、文档（PDF、Word、Excel）、表格等多模态信息进行智能解析，将非结构化内容转化为可检索、可分析的结构化文本，解析结果支持人工复核。

## <a id="_Toc239152408"></a><a id="_Toc239152266"></a>（二）结构化提取要素

针对投前、投后不同业务场景，提取以下关键要素：

__要素类别__

__提取字段__

__用途__

项目要素（投前项目）

公司名称、所属行业、核心技术、融资阶段、投资金额、项目简介、联系方式

投前项目清单整理、潜在项目入库

舆情要素（投后及潜在项目）

事件主体、事件类型、发生时间、情绪倾向（正面/中性/负面）、影响程度

投后舆情监测与潜在项目风险研判

发文机关、文号、发布时间、主题领域、影响方向

知识库入库与政策影响分析

## <a id="_Toc239152409"></a><a id="_Toc239152267"></a>（三）研判置信度评分

每条研判结论附置信度评分（0~1），用于衡量智能体研判的可信程度。置信度基于信息来源权威性、证据充分性、推理链完整度等维度综合计算。

项目详情页展示研判置信度汇总值：取该项目所有研判结论中的最高置信度，作为该项目整体研判可信度的参考指标；无结论时使用系统默认值。置信度评分随模型迭代与反馈数据积累持续优化。

## <a id="_Toc239152410"></a><a id="_Toc239152268"></a>（四）数据质量保障

去重归并：同源信息自动去重，重复推送的预警信息归并处理；

置信度标注：对智能提取与研判结果标注置信度，供人工参考；

来源引用：分析结论自动关联原始信息来源，支持溯源复核；

人工复核：关键提取结果与研判结论经业务人员复核确认后生效。

# <a id="_Toc239152269"></a><a id="_Toc239152411"></a>六、信息归集与知识管理需求

## <a id="_Toc239152270"></a><a id="_Toc239152412"></a>（一）长效政策信息——投研知识库

入库范围：具有持续影响的政策类信息（含内部政策），如国家发改委、交通运输部等部门发文，用于战略必要性、流程合规性判断。

管理方式【建议】：政策信息按发文机关、文号、发布时间、主题领域等要素结构化管理，长期有效、可全文检索。

对报告输出的辅助：智能体生成报告"政策影响分析"等章节时，自动从知识库引用相关政策条文并标注出处。

对对话交互的辅助：对话问答涉及政策类问题时，智能体以知识库为权威检索来源，回答引用政策原文与文号。

## <a id="_Toc239152413"></a><a id="_Toc239152271"></a>（二）短期舆情信息——舆情信息库

入库范围：已投项目相关舆情信息（含专家渠道获取的非公开信息），暂不纳入正式知识库。

管理方式【建议】：舆情信息按主体、事件类型、时间、核实状态管理，状态流转为"待核实—已核实—处置—归档"。

对报告与对话的辅助：报告引用舆情并标注核实状态，未核实信息不写入结论；对话中作为时效性提示，标注"待核实"与来源。

## <a id="_Toc239152414"></a><a id="_Toc239152272"></a>（三）两类信息协同【建议】

同一主体同时存在政策影响与舆情事件时，报告与对话中分区呈现、分别标注，确保权威政策依据与时效舆情提示界限清晰。

## <a id="_Toc239152415"></a><a id="_Toc239152273"></a>（四）内部资料入库

系统需增设内部资料上传通道，支持财务报表、内部跟踪评价报告、尽调资料等多格式（Excel、Word、PDF等）入库。上传后系统自动解析并标记处理状态（已入库/待解析），支持按状态筛选与检索。鉴于内部资料格式多样，需业务侧先行完成格式规范及模板、规则整理，再由我方进行数据处理入库，以支撑知识库与智能对话应用。格式规范与模板整理由投资部组织推进【待确认】。

# <a id="_Toc239152296"></a><a id="_Toc239152438"></a>十、对话交互需求

## <a id="_Toc239152439"></a><a id="_Toc239152297"></a>（一）对话能力范围

投前研判：潜在项目分析、行业研究、产业链问答、竞品分析；

投后分析：在管项目舆情、风险、政策影响问答；

知识检索：知识库政策条文检索、信息库舆情查询；

报告生成：对话发起报告生成，按模板输出结构化报告。

## <a id="_Toc239152440"></a><a id="_Toc239152298"></a>（二）对话交互链路

对话交互完整链路为：对话提问—智能体理解意图—检索知识库与信息库—分析推理—输出回答或报告。智能体在对话中自动判断问题类型，优先引用权威信息源，对时效性信息标注来源与核实状态，确保回答可追溯。

## <a id="_Toc239152299"></a><a id="_Toc239152441"></a>（三）研判结论筛选

研判结论支持多维度筛选：按时间范围（近7天/30天/90天）筛选，按处理状态筛选（已反馈\[采纳/误判\]/待反馈），便于业务人员快速定位关注内容。

## <a id="_Toc239152300"></a><a id="_Toc239152442"></a>（四）对话反馈与模型优化

经原型演示确认，每轮对话支持正确研判与误判的正负反馈，用于模型持续迭代优化。反馈数据集中管理，支撑系统不断提升研判准确性。

# <a id="_Toc239152452"></a><a id="_Toc239152310"></a>十四、数据安全与合规需求

数据不出域：系统部署于集团内部算力环境，投资数据不向外部传输；

权限隔离：按岗位角色进行数据权限隔离，敏感信息分级管控；

操作留痕：全流程操作记录可审计，关键操作可追溯；

非公开信息管控：专家渠道获取的非公开信息按权限范围访问，严格限定知悉范围；

外部数据合规：外部数据对接（含千里马等平台）须先行开展合规性审查，明确数据获取方式的合法合规性后方可实施。
