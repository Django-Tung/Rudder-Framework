# 预设 P1 · 清爽后台（**默认**）

> 克制、企业感、通用性最强。**不确定选什么就选这个。**

## 色板

```text
主色  ██ #2563eb   brand-600    按钮、主强调、选中态
浅主  ██ #dbeafe   brand-100    标签底色、提示条
页面  ██ #f8fafc   surface-page 页面背景
卡片  ██ #ffffff   surface-card 卡片、面板、表格
文字  ██ #0f172a   text-primary 标题与正文
次文  ██ #475569   text-secondary 说明文字
弱文  ██ #94a3b8   text-muted 占位提示、时间戳
边框  ██ #e2e8f0   border-base  卡片边框、分隔线
危险  ██ #dc2626   danger-600   错误态
成功  ██ #16a34a   success-600  成功态
```

## 字阶

| 层级 | 字号 / 行高 / 字重 | 用在哪 |
|---|---|---|
| title | 24px / 32px / 700 | 页面主标题、弹窗标题 |
| subtitle | 18px / 28px / 600 | 区块标题、卡片标题 |
| body | 16px / 24px / 400 | 正文、表单、表格内容（**基准字号**） |
| caption | 12px / 16px / 400 | 辅助说明、时间、标签 |

## 版式

```text
圆角  小 4px   中 8px   大 12px
间距  页面 24px  卡片内边距 24px  区块间 32px
阴影  sm 极轻（默认）  md 仅用于浮层（下拉、Modal）
```

|                                                              |
|  +--------------------------------------------------------+  |
|  |  筛选条：输入框 ▭   下拉 ▾   [查询] [重置]             |  |
|  +--------------------------------------------------------+  |
|                                                              |

|  |  表格：表头 浅灰底                                     |  |

## 移动端线框

```text
+----------------------+
|  页面标题            |  ← 顶栏折叠为汉堡菜单
+----------------------+
|  [输入框       ]     |  ← 筛选条纵向堆叠
|  [下拉 ▾      ]      |
|  [      查询      ]  |
+----------------------+
|  卡片 1              |
|  卡片 2              |  ← 表格在窄屏下
|  卡片 3              |     转为纵向卡片列表
+----------------------+
|      < 1 2 3 >       |
+----------------------+
```

## 适合什么客户

- ✅ B 端管理系统、后台、内部工具（**最通用**）
- ✅ 面向企业客户的业务系统
- ✅ 需要专业、克制、可信赖观感的场合

## 不适合什么客户

- ❌ 消费级 / C 端产品（偏商务）→ 考虑 P3
- ❌ 监控大屏 / 长时间盯着看的场景 → 考虑 P2
