# 快速开始

> 第一次用 Rudder，**只读这一页**就够了。
> 需要更多细节时再看 [新手教程](getting-started.md)。

---

## 我想做一个原型

**你手上有完整的需求文档吗？**

- **有**（`.docx` / `.md` / `.txt`）→ 走 `/rudder-import 你的文档.docx`
- **没有**，只有一个想法 → 直接 `/rudder-plan 用一句话描述你想做什么`

### 两种方式接下来都会做的事

```text
① AI 会反问你 1-3 个问题
      ↓  👉 认真回答。这一步直接决定成品质量
② AI 给你看两份文档
      · plan.md   —— 你要什么（业务、流程、验收标准）
      · layout.md —— 页面长什么样（布局草图）
      ↓  👉 看不懂就问 AI，别硬着头皮批准
③ AI 写代码 → ④ 你在浏览器里看效果 → ⑤ 满意就提交
```

## 我现在能做什么

| 你想做的事 | 输入这个 |
|---|---|
| 我有一份需求文档，要拆成多个功能 | `/rudder-import 文档.docx` |
| 我有个想法，想做个原型 | `/rudder-plan 我想做一个供应商列表页` |
| AI 给我看了计划，我确认没问题 | `/rudder-plan-confirm REQ-001` |
| 计划已批准，开始写代码 | `/rudder-implement REQ-001` |
| 做出来了，但不满意（**需求没变**） | `/rudder-adjust REQ-001 具体哪里不对` |
| 我临时要加个功能（**需求变了**） | `/rudder-change REQ-001 增加按状态筛选` |
| 满意了，提交存档 | `/rudder-commit REQ-001` |

> ⚠️ **调 `plan-confirm` 不等于批准**——批准是你明确回一句「PRD 批准，状态改为 APPROVED」。

## AI 停下来了，要我回答问题

**这是正常的，不是出错。** 框架故意让 AI 在不确定时停下来问你，而不是自己猜。

| AI 说 | 你该做什么 |
|---|---|
| 「需要你确认」 | **回答它问的那个具体问题**，不要重复你最初的原话 |
| 「请选择 UI 风格」 | 看 [`docs/styles/`](styles/README.md) 挑一个；拿不准就说「你决定」 |
| 「请完善假数据基线」 | 说一句你的业务是什么；或说「你决定」，AI 会按行业生成合理的 |
| 「不能修改代码，等你批准」 | 说明 `plan.md` 还是草稿，去跑 `/rudder-plan-confirm` |
| 「依赖未满足，REQ-002 还是 DRAFT」 | 先完成 REQ-002，或让 AI 帮你改 `deps` |

## 出错了怎么办

| 症状 | 怎么办 |
|---|---|
| 页面报错 / 功能没实现 | 说清**复现步骤 + 实际结果 + 预期结果**，这是**实现缺陷**，走 `/rudder-adjust` |
| 做出来的东西完全不对 | 说明**需求本身理解错了**，走 `/rudder-change` 或开新 REQ |
| AI 反复问同一个问题 | 明确给答案，或直接说「用默认值」 |
| `npm run check:req` 报错了 | 把完整报错贴给 AI，它会按异常流转规则处理 |
| 改了代码但页面没变 | 确认 `npm run dev` 还在运行，并刷新了浏览器 |

### 记住这一句就够了

> **需求本身没变，只是做得不对 → `adjust`**
> **需求本身变了（多了一个功能）→ `change`**

## 做完了，我怎么看到效果

```bash
npm run dev
```

浏览器打开终端里显示的地址（通常是 <http://localhost:5173>）。

**演示给客户之前**，走一遍 [`docs/demo-checklist.md`](demo-checklist.md)——
尤其是「断网演示」那一节：会议室投屏时网络经常不可靠，本项目做了零外网依赖，
但需要你自己确认一遍。

每个需求在 `implement.md` 里都有一份 **「演示动线」**，AI 已经帮你排好了
从哪进、按什么顺序点、怎么收尾，照着走就行。

## 你会看到很多英文状态词

比如 `PLANNED`、`IMPLEMENTING`、`COMMITTED`。

**不用管它们。** 那是框架内部的记账用的，AI 每次都会附一句人话告诉你：

| 你会听到 | 意思 |
|---|---|
| 📝 需求还在起草，你可以随便改 | 放心改，改多少都行 |
| ✅ 需求已定稿，AI 可以动手写代码了 | 该你批准了 |
| 🔨 正在写代码 | 等一会儿 |
| 🧪 代码写完了，打开看看满不满意 | 该你验收了 |
| 📦 已提交存档 | 这个需求完事了 |
