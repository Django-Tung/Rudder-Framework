# UI 风格预设

> 你的项目界面**长什么样**，从这三套里挑一套。
> 规范见 [`.rudder/design/visual.md`](../../.rudder/design/visual.md)。

## 三套预设怎么选

| 预设 | 一句话 | 适合 | 看图 |
|---|---|---|---|
| **P1 · 清爽后台** | 克制、专业、通用 | B 端管理系统、企业内部工具 | [看图](p1-light-console.md) |
| **P2 · 深色数据台** | 深色、信息密、监控感 | 运营中心、监控大屏、数据看板 | [看图](p2-dark-console.md) |
| **P3 · 温暖内容型** | 留白多、亲和、有品牌感 | C 端产品、营销页、消费品牌 | [看图](p3-warm-content.md) |

**拿不准就选 P1** —— 它通用性最强，绝大多数企业客户都不会挑出问题。

## 你也可以说「你决定」

不确定的话，直接跟 AI 说**「你决定」**就行，会用默认的 **P1 · 清爽后台**。
这不会影响项目往下走。

## 还有一种情况：客户有自己的品牌色

如果客户给了你品牌色手册或 Logo 规范，选 **BRAND（品牌派生）**：
AI 会用客户的主色，配上 P1 的字体、间距和圆角。

> 这样做的原因：只换颜色，界面风格仍然和你项目里其他页面保持一致。

## 换预设之后

替换 `src/index.css` 里的整个 `@theme` 块即可。
**页面代码一个字都不用改**——因为代码里用的是「标题色」「主按钮」这类语义名，不是具体颜色。
