# 全局主 PRD

> 本文件是项目级需求主记录。它记录跨 REQ 共享的业务规则、术语、已确认的 UI 主风格和待批准的需求拆分。
> 不属于任何阶段，不设置 `status` / `phase`。REQ 的状态与索引由各 REQ 的 `README.md` 和自动索引维护。

## 1. UI 主风格

- 状态：`CONFIRMED`
- 风格名称：数据密集型投研工作台
- 风格描述：面向投研人员的高信息密度、可筛选、可追溯的工作台界面，突出项目、指标、舆情、研判和报告等业务信息的快速浏览与操作。
- 确认日期：2026-09-24
- 适用范围：全项目；单个 REQ 如需例外，必须在对应 `plan.md` 记录原因并经人工确认。

> 首次执行 `/rudder-import` 或 `/rudder-plan` 时必须向用户确认主风格。后续入口必须展示当前风格并询问是否沿用或调整，未确认不得写入正式 PRD。

## 2. 全局业务规则

> 仅记录已由用户确认、且跨多个 REQ 共享的规则；候选项先放在入口的澄清问题中。

- UI 主风格为数据密集型投研工作台，强调项目、指标、舆情、研判和报告信息的高密度浏览、筛选与追溯。
- 无研判结论时，置信度显示为“暂无研判”，不参与项目整体最高置信度计算。
- 产业链分析与主动寻源不纳入本期范围。
- 千里马平台对接纳入功能边界，但本期使用模拟对接；真实接入须通过合规审查。
- 小程序指标分享复用现有账号体系，仅展示核心指标，并遵循有效期、登录和脱敏要求。
- 复合模式、正式预览、电子印章本期不纳入报告中心范围。

## 3. 术语表

> 仅记录已确认的项目术语及其定义。

- 数据密集型投研工作台：面向投研人员、支持高密度浏览、筛选和追溯项目、指标、舆情、研判及报告信息的 Web 工作台。
- 在管项目：当前已投入并由投后团队持续管理的项目，本期包含广东粤通启源芯动力科技有限公司、中储智运科技股份有限公司、北京市建筑设计研究院股份有限公司、车库电桩控股（深圳）有限公司和中数睿智。
- 潜在项目：尚未投资、处于线索或持续跟进阶段的项目。
- 研判置信度：基于来源权威性、证据充分性和推理链完整度衡量研判可信程度的 0~1 评分。
